# Number System Logical Programs for Interview (Python)

This repository contains a collection of Python logical programs related to Number System concepts commonly asked in technical interviews. The code examples are organized in the `python_logical_programs` directory.

## List of Covered Topics

- **Base Conversions**
  - Binary, Decimal, Octal, Hexadecimal conversions
- **Number Properties**
  - Palindrome numbers
  - Armstrong numbers
  - Perfect numbers
  - Prime numbers
  - Even/Odd number checks
  - Factorial calculation
  - Strong, Automorphic, Harshad, Neon, Magic, Amicable, Friendly numbers
- **Digit Operations**
  - Sum of digits
  - Reverse a number
- **GCD, LCM, HCF Calculations**

## Usage

You can browse and use the code in the `python_logical_programs` folder for practice and interview preparation. Each file focuses on a specific logical question or number system concept.
